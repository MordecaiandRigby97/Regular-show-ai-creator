# Regular Show AI Creator

Tools for pitching Regular Show inspired video and movie concepts featuring the
original voice actors plus new cast members Sydney Jayla, Emily Rose, and Jaylan.

## Usage

Run the module in video mode to generate a short-form outline:

```bash
python -m regular_show_creator video
```

Or generate a feature-length treatment outline:

```bash
python -m regular_show_creator movie
```
