# Regular Show AI Scene Generator

This project is a simple, one-file AI scene generator for "Regular Show". You can use it directly in your web browser without any installation.

## How to Use

Follow these simple steps to get started:

### 1. Download the File
- Click on the `regular-show-ai.html` file in the file list.
- Click the "Download" or "Raw" button to save the file to your computer (e.g., in your Downloads folder).

### 2. Open the File in Your Browser
- Find the `regular-show-ai.html` file you just downloaded on your computer.
- Double-click the file to open it in your web browser (like Chrome, Firefox, or Safari).

### 3. Add Your API Key
- The webpage will have a text box asking for your OpenAI API key.
- Copy your API key from your [OpenAI account](https://platform.openai.com/account/api-keys) and paste it into the box.
- **Note:** Your key is only used to communicate with OpenAI for the scene generation and is not stored or saved anywhere.

### 4. Generate a Scene
- Click the "Generate Scene" button.
- A new, original scene script will appear in the text box below!

That's it! You can now generate as many scenes as you like for your videos.
