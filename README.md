# Regular Show AI Creator — Floyd Sneed Tribute Studio

This project is a single-page tribute experience honoring drummer **Floyd Sneed** of Three Dog Night.
It was built with the spirit of the Regular Show voice cast, who act as virtual hosts for movies,
interviews, and other activation ideas.

## Getting Started

1. Open `index.html` in any modern browser.
2. Explore the hero section, band member highlights, and Regular Show host breakdowns.
3. Use the **Floyd Sneed Media Studio** form to add movie concepts, interview prompts, or other
   commemorative initiatives. Entries instantly render under the selected tab.

No build tools or dependencies are required — it's pure HTML, CSS, and vanilla JavaScript.
